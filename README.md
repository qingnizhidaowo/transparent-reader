# 透明网页阅读器（Transparent Reader）

一个基于 Electron 的桌面悬浮透明浏览器：把任意网页变成**半透明、置顶、可穿透**的悬浮小窗，**鼠标移出自动隐藏、移回自动显示**——压在文档、表格、IDE 上悄悄阅读，来人之前鼠标一甩窗口就消失。

## 功能特性

- **整窗透明**：工具栏滑块实时调节 10% ~ 100% 透明度（默认 40%），也可以在托盘菜单里按档切换
- **背景透明（仅文字与图片）**：Ctrl+Alt+G 或工具栏「T」按钮切换——**除文字与图片外一切完全透明**：网页背景被剥离（保留原色与表格线条），应用自身工具栏/阅读栏底色也全部去除，内容直接悬浮在壁纸上；工具栏保持常显（透明底色，不遮挡内容）。v1.4.1 起以**用户级样式表**注入剥离规则，网页用 `!important` 写死的白底、行内样式、SPA 动态插入的样式以及 **iframe 子框架**里的白底也一律剥掉
- **移出即隐藏 / 移入即显示**：鼠标离开窗口立即隐藏（默认无过渡动画、无等待），移回窗口原位置立刻显示，**全程不抢焦点**；正在打字或拖动窗口时不会误触隐藏
- **置顶悬浮**：默认以 screen-saver 层级置顶，压在所有窗口之上（可关闭）
- **鼠标穿透**：开启后窗口只保留显示、点击全部穿到底层应用（forward 模式，悬停仍有效）
- **网页/阅读双模式**：地址栏直达任意网页（webview 渲染，不受 iframe 限制，B 站、知乎都能开）；新标签链接自动在本窗口内跳转，不弹新窗口；一键提取正文进入沉浸阅读模式，自动去广告去导航，小说类内容自动首行缩进
- **最小化到托盘**：工具栏「—」或系统最小化（Win+Down 等）都直接隐藏到托盘，并暂停"移入自动弹出"（避免鼠标扫过误弹），双击托盘图标即可呼出；托盘右键完整菜单（置顶/穿透/背景透明/自动隐藏/过渡动画/透明度/退出）
- **全局快捷键**：窗口藏起来也随时可控
- **细节保护**：正在地址栏/网页里打字、拖动、缩放窗口时不会触发自动隐藏

## 快速开始

环境要求：Node.js ≥ 18（Windows / macOS / Linux 桌面均可）。

```bash
npm install        # 首次安装（国内网络可加：ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/）
npm start          # 启动
```

启动后先看到本地引导页，在顶部地址栏输入网址回车即可开始遨游；直接输入文字则自动用必应搜索。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Alt+G` | 背景透明·仅文字模式（背景全透明、文字全清晰；切换会刷新窗口并恢复当前页） |
| `Ctrl+Alt+H` | 手动显示 / 隐藏窗口（手动隐藏后鼠标扫过原区域**不会**自动弹出，再按一次恢复） |
| `Ctrl+Alt+T` | 开关鼠标穿透 |
| `Ctrl+Alt+B` | 呼出窗口并聚焦地址栏 |
| `Ctrl+Alt+=` / `Ctrl+Alt+-` | 网页缩放（阅读模式下调正文字号），小键盘加减号同样有效 |
| `Ctrl+Alt+0` | 重置缩放 / 字号 |
| `Ctrl+Alt+Q` | 退出应用 |
| `Ctrl+L`（窗口内） | 聚焦地址栏 |
| `F12`（窗口内） | 开发者工具（排障用） |

## 显隐机制说明

- 主进程每 100ms 读取一次全局光标坐标，与窗口矩形比较：在外→**立即隐藏**（默认无过渡动画、无等待）；回到区域内→立即显示。过渡动画可在托盘菜单开启，默认关闭
- 穿透模式下仍保留 2.5 秒宽限，避免操作底层应用时窗口闪烁
- 窗口隐藏后位置信息保留，"原区域"即热区。两种隐藏语义不同：鼠标移出触发的自动隐藏仍保持"移入自动显示"（核心体验）；工具栏「—」与系统最小化为最小化到托盘，会**暂停移入自动显示**，双击托盘图标 / Ctrl+Alt+H / 托盘菜单呼出后恢复；Ctrl+Alt+H 手动隐藏同样暂停自动弹出
- 打字保护：地址栏输入中、或 1.5 秒内在网页里有键盘活动（如搜索框输入）时不隐藏，避免"打着字窗口没了"

## 常见问题

**Q: 窗口太透明/看不清？** 拖动工具栏滑块或托盘菜单「透明度」调高；85% 以上接近不透明。

**Q: 开了鼠标穿透点不到自己窗口了？** 按快捷键 `Ctrl+Alt+T` 关闭，或用托盘菜单。开启时工具栏会有 toast 提示。

**Q: 窗口隐藏后找不到了？** **双击托盘图标**，或 `Ctrl+Alt+H` / `Ctrl+Alt+B` / 托盘右键菜单。最小化与手动隐藏后都不会因鼠标扫过而自动弹出，呼出一次后恢复。

**Q: 点「—」或最小化后窗口去哪了？** 已隐藏到托盘且暂停了"移入自动弹出"（鼠标扫过原区域不会弹出）：**双击托盘图标**即可呼出，也可 Ctrl+Alt+H / Ctrl+Alt+B 或托盘右键菜单选择显示；系统级最小化同样被接管为托盘隐藏，不会"卡死"在任务栏。

**Q: 背景透明模式下网页还有白色背景？** v1.4.1 已修复：早期版本用普通层级（author）注入剥离样式，遇到考试、答题、后台管理类网站用 `!important` 写死的白底、或正文装在 iframe 里的页面就会被压过/覆盖不到，表现为“除文字图片外还剩一块白底”。现在剥离样式由主进程以**用户级样式表**（`cssOrigin: 'user'`，CSS 级联中优先级高于网页一切 `!important`）注入，并对每个 iframe 子框架补注入，白底会连同应用底色一起完全透掉。仍有个别极端情况（如用 `<canvas>` 画布自绘背景、SVG 内部白色矩形）无法用 CSS 剥除，属已知边界。

**Q: 背景透明模式下文字看不清？** 该模式保留网页原始文字颜色：深色文字配浅色壁纸、浅色文字配深色壁纸效果最佳；若当前壁纸与站点文字颜色相近导致难辨认，可换壁纸或 Ctrl+Alt+G 退回整窗透明模式。

**Q: 背景透明模式下怎么操作窗口？** 工具栏保持常显（底色全透明，只剩图标与地址栏），输网址、点按钮照常；拖动窗口拉工具栏空白处；调整大小拖**右下角**的斜纹手柄；透明度滑块在此模式下自动隐藏（一切本就透明）。

**Q: 切换背景透明模式时窗口闪了一下？** Electron 限制透明窗口必须在创建时指定，因此切换会重建窗口（位置与当前页面自动恢复），属正常现象。

**Q: 点击链接没反应？** v1.1 已修复：`target="_blank"`、`window.open` 的新标签链接现在会直接在本窗口内自动跳转（旧版本 webview 未放行弹窗请求，点击被静默吞掉，表现就是“点了没反应”）。个别弹窗式登录会接管当前页面，点工具栏「后退」即可返回。

**Q: 某些站点白屏/加载失败？** 多为该站点网络或反爬策略所致，可尝试刷新或换个入口页；新开标签的链接会在窗口内自动跳转。

**Q: Linux 下透明度无效？** 整窗透明依赖桌面合成器（Compositor）。GNOME/KDE 默认开启；某些轻量 WM（如未开合成器的 i3、openbox）下会退化为不透明，但显隐、穿透等功能不受影响。

**Q: 阅读模式提取不到正文？** 提取依赖页面中存在常规段落（`p` 等标签），SPA 动态渲染或纯图流页面可能提取失败，此时保持网页模式浏览即可。

## 打包为独立可执行文件（可选）

安装打包器后一条命令出安装包：

```bash
npm install --save-dev electron-builder
npx electron-builder --win nsis     # Windows 安装包（亦可 --mac dmg / --linux AppImage）
```

可在 `package.json` 中增加 `"build": { "appId": "com.moyu.transparent-reader", "productName": "TransparentReader" }` 等配置。

## 技术说明

窗口采用 `frame: false` + `setOpacity()`（分层窗口）而非 `transparent: true`：Windows 上后者的整窗透明度调节不可用，而前者三平台均稳定，且保留了原生边缘缩放；无边框窗口通过工具栏 `-webkit-app-region: drag` 拖动。「背景透明」模式因 Electron 限制需重建为 `transparent: true` 窗口（位置与当前页面自动恢复），并通过向 webview 注入 CSS 剥离网页全部背景、但保留网页原始文字颜色、图片与表格边框（v1.4 起应用自身 UI 底色也全部透明、工具栏常显）；v1.4.1 起注入由主进程执行且使用 `cssOrigin: 'user'` 用户级样式表（级联优先级压过网页自身任何 `!important` / 行内 / 动态插入样式），并监听 `frame-created` / `did-frame-navigate` 经 `WebFrameMain.executeJavaScript` 向全部 iframe 子框架幂等补注入；此模式下 Windows 原生边缘缩放失效，由右下角拖拽手柄兜底。网页由 `<webview>` 独立进程渲染，天然绕开 iframe 的 X-Frame-Options 限制；提取脚本在注入层完成清洗（剥离脚本、内联事件与危险协议）后才进入阅读面板。
